# java-racingcar-precourse

# 추가 문제 정의

1. 자동차의 수 N을 몇 개로 정의할것인가?
    - 개수가 너무 많으면 출력이 너무 많아짐. 자동차의 수는 최대 10
2. 자동차의 이름 규격 추가 정의
    - 이름에는 공백이 올 수 있으며, 공백으로만 이루어진 이름은 허용되지 않음
    - 쉼표가 연달아 올 수 없음
    - 사용자의 이름은 알파벳, 숫자만 가능함
3. 시도할 횟수 T의 제한은 몇으로 할 것인가?
    - 시도할 횟수 T도 너무 많으면 출력이 길어짐. 시도할 횟수 T는 20
4. 매 라운드 및 승자의 이름을 출력하는 순서는?
    - 입력으로 들어온 순서를 유지해야 함
5. 자동차가 하나도 없이 빈 문자열이 들어오는 경우는?
    - 오류로 간주
6. 시도할 횟수가 0일 때는 어떻게 처리할 것인가?
    - 정상으로 간주
7. 중복된 이름이 있는 경우
    - 오류로 간주

# 구현해야 할 사항

## 기능 정의

1. 자동차 객체
    - [ ]  자신의 이름을 가져야 함
    - [ ]  현재 위치를 가져야 함
    - [ ]  랜덤 값에 따라 전진 여부를 결정하는 기능
2. 그 외의 기능
    - [ ]  매 라운드마다 자동차의 움직임을 실행하는 기능
    - [ ]  라운드 실행 횟수를 받아서 정해진 횟수만큼 각 라운드를 실행하는 기능
    - [ ]  현재 라운드의 자동차 위치를 종합하는 기능
    - [ ]  라운드가 종료하였을 때 가장 멀리 간 자동차를 찾는 기능
    - [ ]  입출력 기능

## 고려해야 할 예외 사항들

- [ ]  자동차 정보가 비어있거나 개수 제한보다 많이 들어온 경우
- [ ]  자동차 이름이 공백으로 들어오는 경우
- [ ]  자동차 이름의 길이가 5자보다 큰 경우
- [ ]  자동차 이름에 특수문자가 들어오는 경우
- [ ]  쉼표 구분자가 한번에 여러개 오는 경우
- [ ]  시도할 횟수가 음수이거나 제한보다 큰 값이 들어온 경우
- [ ]  동일한 이름이 존재하는 경우
- [ ]  진행 상황과 결과 발표의 이름 순서가 유지 되는지
- [ ]  전진 시도 시 0~1만큼 움직이는지

## 객체 정의

- **Model**
    - **car**
        - 자동차와 관련된 객체들
        - CarName
            - 인스턴스 : 이름, 최대 길이, 이름 패턴
            - 기능 : 이름에 대한 정보 및 유효성 검사
        - Car
            - 인스턴스 : CarName, 현재 위치
            - 기능 : 이름 조회, 현재 위치, 전진
        - Cars
            - 인스턴스 : List<Car>
            - 기능 : 자동차 전진 여부 결정, 자동차 전진 수행, 우승자 계산
    - **strategy**
        - 전진 전략과 관련된 객체들
        - MoveStrategy
            - 기능 : 전진 여부를 결정하는 전략 인터페이스
        - ThresholdMoveStrategy
            - 인스턴스 : 정수 공급자, 임계값
            - 기능 : 정수 공급자에서 획득한 정수를 기반으로 임계값에 따라 전진 여부 결정
    - **provider**
        - 정수 공급자와 관련된 객체들
        - NumberProvider
            - 기능 : 정수를 제공하는 인터페이스
        - RandomNumberProvider
            - 기능 : 0에서 9 사이의 랜덤 정수를 제공
        - SequenceNumberProvider
            - 인스턴스 : 정수 리스트
            - 기능 : 리스트에 정의된 정수를 순차적으로 제공
- **Service**
    - RaceService
        - 인스턴스 : MoveStrategy
        - 기능 : 시도한 횟수 만큼 Cars의 일괄 전진을 수행. 수행 후 결과를 반환. 우승자 계산
    - ParseService
        - 기능 : 입력된 자동차 이름 문자열을 파싱하여 List<String> 으로 반환
- **Controller**
    - RaceController
        - 인스턴스 : RaceService, RaceView
        - 기능 : 입력과 서비스 로직 제어
- **View**
    - RaceView
        - 인스턴스 : InputHandler, OutputHandler
        - 기능 : 입출력 수행
